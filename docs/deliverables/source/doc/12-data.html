Chapter 12Data sources: what is real, how it is fetched and how to verify it

The most important question about a data-driven project is "is this real?". This chapter answers it for every source: what it provides, who provides it, how AegisEO requests it, whether it is live, cached or fixed, whether credentials are involved, how it is processed, whether it worked on 8 November 2026, and how anyone can verify it.

Nothing in AegisEO invents data for a real check: if a source fails, the missing factor is marked missing, confidence is lowered and the result says so.

12.4 How a reader can verify the results

  1. Check the images exist. Under "How we know → Full step-by-step record → Evidence and facts", every image used is listed with a link to its record in the Planetary Computer catalogue (for example https://planetarycomputer.microsoft.com/api/stac/v1/collections/sentinel-1-rtc/items/S1A_IW_GRDH_1SDV_20220827T133609_20220827T133634_044739_055782_rtc). The same images can be found in the Planetary Computer Explorer website by place and date.
  2. Look at the change yourself. "Compare before / after" on the map shows the real optical images on either side of the slider; the radar images are available as layers.
  3. Search the archive live. Step 3's "Check which satellite images exist" lists the passes for any place and dates without starting a check.
  4. Check facilities. Clicking a hospital on the map shows its name; the same object can be found on openstreetmap.org.
  5. Check live alerts on gdacs.org.
  6. Re-check every source with "Check them all again" on the Data sources page.
  7. Reproduce the accuracy numbers with python -m aegis.ml.evaluate after downloading Sen1Floods11, and the agent benchmark with python -m aegis.benchmark (re-run for this report: 12/12 scenarios and 8/8 probes passed).
