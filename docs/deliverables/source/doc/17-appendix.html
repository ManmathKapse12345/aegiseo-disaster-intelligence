Appendix ACommands and settings

A.1 Installing and starting AegisEO

Requirements: Python 3.11 to 3.13, Node.js 20 or newer, and internet access for live data (practice runs work without it). On Windows:

# backend (first terminal)
cd backend
python -m venv .venv
.venv\Scripts\activate
pip install torch --index-url https://download.pytorch.org/whl/cpu    # or /whl/cu126 for an NVIDIA GPU
pip install -r requirements-dev.txt
pip install -e . --no-deps
uvicorn aegis.main:app --port 8000

# frontend (second terminal)
cd frontend
npm install
npm run dev                                                           # http://localhost:5173

Alternatives: docker compose up --build starts PostgreSQL with PostGIS, the API and the web server (http://localhost:8080); deploy\tunnel\start-public.ps1 shares the local installation through a temporary public link; deploy/huggingface and deploy/oracle contain the two cloud deployments.

A.2 Tests and checks

cd backend
python -m pytest                          # 93 tests; the live one is skipped without --network
python -m pytest --network -m network     # live Planetary Computer search
python -m ruff check aegis tests          # Python checks
python -m aegis.benchmark                 # 12 scenarios + 8 safety probes; writes docs/benchmark_results.md

cd frontend
npm run typecheck                         # TypeScript
npm test                                  # Vitest unit tests
npx playwright test                       # end-to-end; E2E_WEB_PORT / E2E_API_PORT move the ports
npm run build                             # production build in frontend/dist

A.3 Reproducing the trained models

cd backend
python scripts/download_sen1floods11.py --out ../data/datasets/sen1floods11              # about 1.8 GB
python -m aegis.ml.prepare --raw ../data/datasets/sen1floods11 --out ../data/datasets/sen1floods11_prepared
python scripts/train_all.py --data ../data/datasets/sen1floods11_prepared --models ../models
# the evaluation writes models/evaluation.json and models/selection.json
python -m aegis.ml.evaluate --data ../data/datasets/sen1floods11_prepared --models ../models

A.4 Main settings

All settings are environment variables beginning with AEGIS_, read from the environment or from a .env file (a template without values is .env.example). Values marked "secret" are stored so that they are never printed or returned by the API.

SettingDefaultEffect
AEGIS_MAX_AOI_KM2 / AEGIS_MIN_AOI_KM21500 / 0.25Largest and smallest area per check (safety check G02 and the interface, through /api/config).
AEGIS_DEFAULT_RESOLUTION_M20Pixel size when a request does not give one.
AEGIS_MAX_GRID_PIXELS2,600,000Pixel budget; above it the pixel size is coarsened in 10 m steps.
AEGIS_WORKER_THREADS2Checks that can run at the same time.
AEGIS_TORCH_DEVICEautocpu, cuda (NVIDIA GPU) or automatic choice.
AEGIS_OFFLINEfalseNo network access; only saved data is used.
AEGIS_DATA_DIR, AEGIS_DATABASE_URLdata/, SQLiteWhere the database, saved images and result files are kept; a PostgreSQL address can be given instead.
AEGIS_AUTH_ENABLED, AEGIS_API_TOKENS (secret)false, emptySign-in with tokens and the roles viewer, analyst and admin.
AEGIS_RATE_LIMIT_PER_MINUTE240Requests that change data, per client and minute.
AEGIS_ALERT_WEBHOOK_URL (secret)emptyWhere approved warnings are sent; empty means they stay in AegisEO.
AEGIS_FIRMS_MAP_KEY (secret)emptyNASA FIRMS key for fire detections older than 7 days.
AEGIS_ANTHROPIC_API_KEY (secret), AEGIS_LLM_ENABLEDempty, trueOptional Claude wording of the summary; without a key, templates are used.
AEGIS_RUN_TIMEOUT_S, AEGIS_MC_DROPOUT_SAMPLES1800, 6Defined, but they do not change how a check runs (Section 14.8).

Appendix BAPI endpoints

The backend's interactive API documentation is served at /docs while it runs. Requests are validated strictly (unknown fields are rejected), every error has the same form ({"error": {"code", "message", "request_id"}}), and when sign-in is enabled every request needs a token.

MethodPathPurpose
GET/api/health, /api/health/readyIs the server running; are the database, model and workers ready.
GET/api/configLimits and optional features of this server (new in this round).
GET/api/meThe current user and role.
GET/api/sourcesEvery data source with its live status.
GET/api/events/liveCurrent GDACS alerts and USGS earthquakes.
GET/api/scenarios, /api/places?q=Case studies; place-name search.
POST/api/catalog/previewList satellite passes for an area and dates, without starting a check.
GET/api/dashboard, /api/model, /api/knowledgeOverview figures; the deployed model and its evaluation; the method documents.
POST/api/analysesCreate and queue a check.
GET/api/analyses, /api/analyses/{id}, /{id}/statusList checks; one check with its results; its progress.
POST/api/analyses/{id}/cancel, /{id}/rerunStop a check; run a copy again.
DELETE/api/analyses/{id}Delete a finished check (admin).
GET/{id}/detections, /{id}/priorities, /{id}/facilitiesDetected areas, priority squares and places as GeoJSON.
PATCH/{id}/priorities/{cell_id}A person changes a square's priority, with a reason.
GET/{id}/trace, /{id}/layers, /{id}/reports/{pdf|csv|geojson}, /{id}/exports/products.tifThe full record; map layers; reports; the GeoTIFF of probability, extent and uncertainty.
GET, POST/api/alerts, /api/alerts/{id}/decisionDraft warnings; approve or reject with a note.
GET, POST/api/reviews, /api/reviews/{id}/decisionFindings; decide confirm, false_positive, acknowledge or request_rerun.
GET, POST/api/benchmarks, /api/benchmarks/runBenchmark results; start a benchmark (admin).
GET/metricsOperational measurements for monitoring tools (Prometheus format).
